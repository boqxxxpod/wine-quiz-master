# ワイン検定シルバー：500問問題集

ユーザー提供の知識JSON（864件）から、異なる500件の知識IDを使用した日本語三択問題集です。リポジトリの修正済み150問を全フィールド・順序ごと保持し、新規350問を追加しています。

| ファイル | 内容 |
| --- | --- |
| `wine-quiz-500.json` | 標準の統合500問。`metadata` と `questions` を収録 |
| `batches/wine-quiz-01.json`〜`wine-quiz-10.json` | 50問ずつの確認用データ。番号順に結合すると統合版の `questions` と完全一致 |
| `validation-report.md` | 国別・テーマ別件数、検証結果、既存問題の確認事項 |
| `pilot-150.json` | 既存の修正済み150問。今回の拡充では変更なし |
| `batches/pilot-01.json`〜`pilot-05.json` | 既存150問の30問ずつの分割版。変更なし |

統合版とバッチは同じ問題を含みます。同時に取り込んで二重登録しないでください。正答は0始まりの `correct_index` で指定し、`correct_answer` は対応する選択肢と一致します。

## 解説と出典

新規350問の解説は、元知識・対応する周辺テキスト・既存の検証記録で確認した関連知識に基づく3段構成です。各段を改行し、単一の `explanation` 文字列に保存しています。

- **要点**：問題文を読み直さなくても分かる正答の知識。
- **解説**：背景、具体例、関連する産地・品種・工程など。
- **整理**：似た用語の違いや、産地・品種・年代などの対応。

解説は149〜213字で、全て650字以内です。追加の別ページを使う場合は「参照p.○」を記載しています。統計は確認できる年・比較範囲を示し、年が不明な項目は安定した特徴を問います。日本のワイン史では、1874年の生産記録と試醸の開始、1877年の会社設立を区別しています。

`country`・`countries`・`source_page` は元知識から引き継ぎます。`source_page` は数値と文字列が混在する元資料の値を保持しています。出典は `knowledge_id` と `source_page` で参照でき、追補の根拠は [既存の検証記録](../docs/verification.md#issue-4の変更と確認2026-10-19) に記録されています。

## 検証と承認

全500問の `status` は `auto_checked`、統合版の `metadata.human_approved` は `false` です。`needs_review=true` の9項目を使用せず、既存150問と中心的な知識が重なる追加候補は別の知識IDへ差し替えました。構造・正答キー・重複・分割一致は `node scripts/verify_standard_pack.mjs` で検証できます。

出典との意味の照合と誤答候補の確認は自動レビューであり、人による最終承認を済ませた状態にはしていません。既存150問の一部には統計年を問題文に明示していない設問が残っていますが、今回の保持条件に従って変更せず、[検証レポート](validation-report.md) に記録しています。

元の150問のメタデータは `metadata.original_metadata` に保持し、500問版の件数と編集記録を別途記録しました。既存メタデータ内のスペイン15問や `app_import_compatible: false` は作成当時の記録です。現在のアプリはpilot形式に対応し、表示件数は実際の `questions[].countries` から集計します。

## アプリでの扱い

サーバー版・GitHub Pages版の標準問題集として `wine-quiz-500.json` を自動で読み込みます。選択肢をシャッフルしても、元の正答に対応するIDで採点します。「別の問題集 JSON」では既存のpilot形式、ネイティブ30問形式、承認済みの `version: 1` 書き出し形式も読み込めます。「標準問題集に戻す」で統合500問へ戻ります。

国別の対象は各問題の `countries` 配列で決定します。実集計はフランス149、スペイン61、イタリア66、日本49、アメリカ34、オーストラリア35、ポルトガル33、オーストリア17、ニュージーランド14、アルゼンチン14、南アフリカ17、チリ13問です。

`Q-K0019-01` はフランス・スペイン、`Q-K0491-01` はスペイン・ポルトガルの両方に属します。国別件数の合計は502ですが、「すべて」は重複のない500問です。

## 公開範囲

本リポジトリは公開です。新規の統合版・分割版には原画像、画像ファイル名、Drive URL、周辺原文の全文を含めません。Pagesビルドは `wine-quiz-500.json` だけを元のバイト列のまま同梱します。旧150問版、バッチ、この説明、検証レポートはPages成果物に含めません。サーバー版も統合ファイル1件だけを配信します。
