# ワイン検定シルバー：試験運用150問

ユーザー提供の知識JSON（864件）から選んだ150件の独立した知識IDをもとにした、3択クイズの**レビュー用データ**です。

- `pilot-150.json`：全150問。全体・国別出題向けの統合データ
- `batches/pilot-01.json`〜`pilot-05.json`：30問ずつの確認用データ
- 3択、正答は `correct_index`（0始まり）、`questions[].countries` は複数国対応の配列
- 5つのバッチは統合ファイルと同じ問題です。同時に取り込んで二重登録しないでください

## 検証と承認

全150問の `status` は `auto_checked`。知識と正答キーの整合・3択・文字列重複・ID重複を機械検証済みですが、誤答選択肢の**意味上の一意性**は人手最終確認前です。`needs_review=true` の知識は使っていません。教材の出典は `knowledge_id` と `source_page` で参照できます。

## アプリでの扱い

ユーザー指定により、サーバー版・GitHub Pages 版の標準問題集として `pilot-150.json` を自動で読み込みます。Issue #4で全150問の `question`・`explanation` を編集し、不要な準拠表現の削除、設問の条件の明確化、理由・背景・誤答との違いの加筆を行いました。同じ問題を持つ5つのバッチにも同じ本文を反映しています。

**スキーマ変更はありません**。ID・選択肢・`correct_index`・`correct_answer`・国情報・出典・`status`・`version`・元メタデータは保持しています。`source_page` は元知識の出典位置で、今回の補足説明すべての直接の引用元を示すものではありません。追補の確認先は [Issue #4の検証記録](../docs/verification.md#issue-4の変更と確認2026-10-19) を参照してください。編集によって `approved` に変更することはなく、人による原資料照合・最終承認は引き続き必要です。

アプリで読み込む際に `question_id`・`options`・`correct_index` を出題用の ID と選択肢に対応付けます。正答の判定は、選択肢をシャッフルしても元の正答に対応する ID で行います。出典表示には `knowledge_id` と `source_page` を使い、原画像・引用・黄色領域を補作しません。

国別の対象は各問題の `countries` 配列で決定します。実集計はフランス32、スペイン16、イタリア17、日本17、アメリカ11、オーストラリア11、ポルトガル11、オーストリア8、ニュージーランド・アルゼンチン・南アフリカ・チリ各7問です。`Q-K0019-01` はフランス・スペインの両方に属し、国別件数の合計は151ですが、「すべて」は重複のない150問です。

`metadata.country_counts` のスペイン15問や、バッチごとのファイルに残る全体件数は作成時点の記録です。表示件数には使わず、実際の `questions[].countries` を集計します。`metadata.app_import_compatible: false` も対応前の履歴として保持しており、現在のアプリはこの形式を読み込めます。元のメタデータは変更せず保持します。

「別の問題集 JSON」では同形式のファイルに加え、従来のネイティブ30問形式と、サーバーで承認した問題の `version: 1` 書き出し形式も読み込めます。「標準問題集に戻す」で統合150問へ戻ります。形式対応や標準問題集への選定は、人による内容承認を意味しません。

## 公開範囲

本リポジトリは公開です。出典画像、Google Driveのリンクやファイル名、元知識の本文コピーは含めません。Pages ビルドは統合ファイル `pilot-150.json` だけを元のバイト列のまま同梱し、バッチやこの説明ファイルを公開成果物に含めません。サーバー版も統合ファイル1件だけを配信し、このディレクトリ全体を公開しません。
