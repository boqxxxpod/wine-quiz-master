ワインの手帖WINE PRACTICE ワイン検定の三択練習

ひとつずつ、たしかに。

今日の練習を、選ぶ。

問題集と範囲、出題数を選んで始めましょう。

01 問題集

wine-quiz-highlighted.json を読み込んでいます。

標準問題集を自動で読み込みます。選んだ JSON は送信せず、このタブでのみ使用します。再読み込みすると標準問題集に戻ります。

02 出題範囲

出題範囲を選択

問題集を読み込んでいます。

03 出題数

選んだ範囲からランダムに出題します。範囲の問題数を超える出題数は選べません。一巡するまで同じ問題は出ません。

答えて、理由を知る。自分のペースで、何度でも。
