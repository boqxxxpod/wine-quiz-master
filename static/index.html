01

Google ドライブを接続

「ワイン検定」フォルダを指定します。

確認中
接続状態を読み込んでいます。

フォルダ URL の folders/ に続く文字列。同名フォルダがある場合は ID で指定します。

Google ドライブの接続手順
  1. Google Cloud で Drive API を有効にし、サービスアカウントを作成します。
  2. サーバーに認証 JSON を保存し、GOOGLE_APPLICATION_CREDENTIALS にファイルパスを設定します。
  3. 「ワイン検定」フォルダを、サービスアカウントのメールアドレスに「閲覧者」で共有します。
  4. フォルダ ID を入力して「写真を同期」を押します。

ChatGPT の Drive 接続は、このアプリには引き継がれません。認証ファイルは公開フォルダや Git に保存しないでください。OAuth を使う場合は、drive.readonly スコープとオフラインアクセスで取得した GOOGLE_CLIENT_ID・GOOGLE_CLIENT_SECRET・GOOGLE_REFRESH_TOKEN をサーバーに設定します。設定後はサーバーを再起動してください。

02

luna を確認

画像入力と利用権限を検証します。

確認中
使用モデルgpt-6-luna
モデルの設定を読み込んでいます。
luna の設定手順
  1. サーバーの環境変数 OPENAI_API_KEY に API キーを設定します。
  2. OPENAI_MODEL=gpt-6-luna を設定し、サーバーを再起動します。
  3. 「利用可否を確認」で、このアカウントからの利用権限を確認します。

OpenAI API のキー・利用権限・課金設定は、ChatGPT の契約とは別に必要です。luna が利用できない場合、生成を停止します。別モデルへの自動切り替えは行いません。API キーをこの画面に入力する必要はありません。

03

黄色部分から問題をつくる

新しい写真・変更された写真だけを処理します。

黄色の検出→文字の読み取り→問題を保存→根拠を確認

文字や黄色の範囲が不鮮明な資料は、確認が必要な資料として保存します。生成した問題は根拠を確認して承認すると、練習に使えるようになります。

生成は取り込み時だけ。
出題・採点・解説表示では API を使いません。
